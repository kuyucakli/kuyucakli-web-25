## Overview

A minimalist progressive web app (PWA) featuring physics-based casual games. The current version includes two games: **Tahterevallis** and **Tilt**(under development). This is an experimental project focused on core gameplay systems rather than content completeness. Supabase is currently used for authentication and will later support progress persistence and leaderboards.

[You can use live app here. ](https://kuyu-games-pwa.vercel.app)
